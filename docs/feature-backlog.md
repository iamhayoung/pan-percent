## 詳細／編集の可読性・操作性（→ feature/recipe-form）

- パン作りの最中（手袋・粉の手）に使う前提で、詳細画面の**文字・タップ領域が小さい**との指摘。
- recipe-form で詳細＝編集を1つの直感的 input UI に統合する際、**文字大きめ・タップ領域大きめ・余白広め**で設計する。必要なら theme の fontSize/spacing 基準そのものを底上げ検討。
- 関連: 表示と編集を分けない統合 UI（memory `recipe-form-percent-editing`）。
- **削除ボタンの置き場所**: 詳細で「削除ボタンだけがポツンと1行ある」配置がしっくりこない、とユーザー。統合編集UIの再設計時に、削除の位置ごと見直す（例: ヘッダーにゴミ箱アイコン／編集導線の中に収める）。破壊的アクションは最大の的にしない（誤タップ防止）。

## 材料プリセット（→ feature/recipe-form）

- よく使う材料を毎回手入力せず、**プリセットから気軽に追加**したい。
- 例: 水 / 塩 / バター / 小麦粉各種（薄力粉・中力粉・強力粉）/ フランス系（T45・T55・T65 …）。
- `isFlour` の初期値もプリセットに含められる（小麦粉系は flour=true 既定）。粉/液体の区別が楽になる。
- 実装案: プリセット定義（多言語名 + isFlour）を持ち、フォームの材料追加時に選択 → 行に展開（g は後入力）。

## レシピのグルーピング／フィルタ（→ 一覧の拡張ブランチ）

- 現状タグは持てるが一覧での絞り込み・グルーピングが無い（本ブランチで意図的に defer）。
- **推奨案: タグのフィルタチップ**を一覧上部に置く（タップで該当タグのみ表示、複数選択可）。
  - 理由: レシピは複数タグを持てるため、「タグでセクション分割」だと1レシピが複数セクションに重複し分かりにくい。フィルタなら重複なく直感的。
  - タブ（recipes/settings）はトップ階層ナビ用なので、動的なタグをタブにするのは避ける。
- 将来: 「グループ表示」トグル等は必要になってから。

## 単位（g 以外 / 国別デフォルト）（→ recipe-form + settings-i18n）

- 材料ごとに **g 以外の単位**（ml, L など製パン・製菓でよく使う）を選べるようにしたい。材料により単位が違うため。
- 国によって基準が違う（g / ポンド lb / oz / L）。**設定画面で基本単位を選べる**ようにもしたい。
- **重要な設計注意 — ベーカー% は重量(g)基準**: 比率は「粉の総重量＝100%」で定義される。
  - **重量系（g / oz / lb）**: 相互変換は単純（比率＝重量比なので % は不変）。表示・入力単位の切替＋設定デフォルトは比較的容易。まずここから。
  - **体積系（ml / L）**: 重量とは密度が必要（水は 1ml≒1g だが油・牛乳・粉は異なる）。% に含めるには材料ごとの密度換算が要る。安易に混ぜると % 計算が壊れる。
  - 方針案: 内部は g 保存、表示/入力で単位変換。体積→重量は密度が要るため、対応材料を限定（例: 水）するか、材料に密度を持たせるかを recipe-form で設計判断。
- settings の「基本単位」は重量系の表示デフォルトとして settings-i18n で。
